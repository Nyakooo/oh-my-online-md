## 详细说明

简记是自托管 Markdown 笔记服务的浏览器客户端。填写自己的服务器地址，点击插件图标或使用快捷键，即可在独立窗口中查看和编辑笔记。

【书写与阅读】
Markdown 编辑与预览、常用格式工具栏、Mermaid 图表、全局搜索、图片粘贴和主题切换。图片先在窗口内预览，保存时才上传。

【文件夹整理】
文件夹直接对应服务器实际目录。拖拽笔记移入、移出或调整顺序；独立笔记显示在文件夹上方。支持文件夹密码访问与重新锁定。

【自己的数据，自己的服务器】
插件连接用户指定的简记服务器，正文与附件存储在该服务器上，不需要开发者提供的笔记云账号。支持服务器访问密码，保存时检查笔记版本，减少多个窗口之间无提示覆盖。

【快捷打开】
默认快捷键为 Ctrl+Shift+Y，macOS 为 Command+Shift+Y；快捷键可在浏览器扩展管理中修改。已有笔记窗口会恢复并聚焦。快捷键默认在浏览器获得焦点时生效。

【只读分享】
可主动生成 1–7 天有效的只读分享链接，并随时撤销。受密码保护的文件夹暂停公开分享。

使用前需要自行部署简记服务器，或取得自己有权访问的简记服务器地址。插件不是离线笔记库，未保存内容仅在当前窗口内存中保留。服务器部署与使用方法请查看项目主页。

开源项目，MIT 许可证。不包含广告或使用行为分析代码，不读取浏览历史，不向网页注入脚本。

## 单一用途

连接用户自行指定的简记服务器，在独立浏览器扩展窗口中查看、编辑和整理该服务器上的 Markdown 笔记。

## 权限用途

- storage：在浏览器本地保存用户指定的服务器地址、会话 Token 与到期时间、窗口尺寸和位置，避免每次重新配置。
- 可选主机权限 http://*/*、https://*/*：用户可自行配置任意自托管服务器地址，因此无法预先列出固定主机。扩展仅在用户提交服务器地址并授权后，对该服务器发起笔记、附件和身份验证请求。浏览器授权按主机匹配，不能精确限制端口或子路径。
- 远程代码：不使用。编辑器、Markdown、Mermaid 和界面 JavaScript 全部包含在扩展安装包中；服务器只提供数据和附件。

## 数据声明核对

扩展会处理认证信息（用户主动输入的密码、会话 Token）和网站内容（用户的笔记、图片与目录），用于核心笔记功能；这些数据与用户指定服务器交互。没有开发者分析、广告、出售或与无关第三方共享的数据用途。外链媒体资源由用户笔记决定。表单中的“处理/收集”口径应按平台定义如实勾选，不应把“开发者不收集遥测”填成“扩展完全不处理任何数据”。

## 审核测试说明

本插件是开源自托管服务的客户端，没有内置公共演示服务器或开发者统一账号。发布者不提供演示服务器，勿填写生产服务器或私人账号。审核人员可以按以下步骤在自己的测试环境验证：

1. 从 https://github.com/Nyakooo/oh-my-online-md 获取项目，按 README 的 Docker Compose 步骤启动服务器。测试环境可将 PASSWORD 留空，不要向公网暴露无密码服务。
2. 在浏览器可访问的环境运行服务器，默认地址为 http://127.0.0.1:10777。若 Docker 运行于其他主机，请改为该测试主机的可达地址。
3. 点击插件图标，填写上述测试地址，允许该主机访问权限。服务器 PASSWORD 为空时插件密码留空，点击“连接并打开笔记”。
4. 新建笔记，输入 Markdown，切换预览，保存并搜索；粘贴图片并保存。
5. 新建文件夹，将笔记拖入/拖出并排序；为文件夹设置测试密码，验证立即锁定、输入密码解锁以及收起后重新锁定。
6. 按 Ctrl+Shift+Y（macOS：Command+Shift+Y）验证窗口恢复；退出连接后可清除该测试环境。

本说明不承诺平台一定接受本地测试流程。如审核要求在线测试入口，需由发布者另行决定，不在提交时虚构账号或服务器。

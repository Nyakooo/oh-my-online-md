## Description

Jianji (简记) is a browser client for your own self-hosted Markdown notes server. Configure a server address, then open a dedicated notes window from the extension icon or a keyboard shortcut. The current app interface is in Simplified Chinese.

WRITE AND READ
Edit and preview Markdown, use formatting tools, render Mermaid diagrams, search saved notes, paste images and switch between light and dark themes. Pasted images stay in the current window until you save.

ORGANIZE WITH FOLDERS
Folders correspond to real directories on your server. Drag notes into or out of folders and reorder notes or folders. Individual notes appear above folders. Password-protected folders support explicit unlocking and relocking.

CONNECT TO YOUR OWN SERVER
Notes and attachments are stored on the server you configure. There is no developer-operated notes cloud or shared account. Server authentication and note-version checks help manage access and concurrent edits.

OPEN WITH A SHORTCUT
The default shortcut is Ctrl+Shift+Y, or Command+Shift+Y on macOS. Configure shortcuts in the browser's extension settings. An existing notes window is restored and focused. Shortcuts work while the browser has focus.

READ-ONLY SHARING
Explicitly create a read-only snapshot link valid for 1–7 days and revoke it at any time. Public sharing is disabled for notes in password-protected folders.

A compatible Jianji server is required. Deploy the open-source server yourself or use a server you are authorized to access. This extension is not an offline notes database: unsaved content is kept in the current window's memory and may be lost if the window is closed or refreshed.

Open source under the MIT license. No advertising or usage analytics. No browsing-history access or webpage script injection. Setup and source: https://github.com/Nyakooo/oh-my-online-md

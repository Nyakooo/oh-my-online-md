# 插件离线使用方案

当前仅保留浏览器插件的独立离线工作空间，无需启动本地服务。

- IndexedDB 保存已保存的笔记、文件夹、排序和 Blob 图片，关闭或重启浏览器后保留。
- 编辑器和界面静态资源随插件安装，外链媒体仍需要网络。
- 本地完整备份包含正文、目录、排序和图片；追加恢复分配新 ID，失败整体回滚。
- 本地总容量默认 200 MiB，可在设置中调整；侧栏显示用量及上限，80% 和 95% 时提醒。单图 10 MiB，单篇正文 16 MiB。
- 本地模式不提供公开分享和密码文件夹，尚未保存的输入只在当前窗口内存中。
- 已部署服务器的直接在线模式保留，与本地库隔离；切换不上传或合并数据。

已撤销本轮新增的本机后端启动增强、自动密码配置、本地笔记导入服务器、服务器离线缓存及双向同步。服务端恢复原有部署及环境变量配置方式，不新增离线相关接口。现有笔记和数据文件不会因撤销代码被删除。

为兼容已运行过新版插件的本地库，原有数据库升级到 IndexedDB v4，保留 notes、folders 和 assets，新增 settings 保存额度与统计缓存；不降级数据库或清空已有内容。遗留同步/导入存储不再读写。

验证结果见 [插件独立离线验证](offline-validation.md)。

在线模式不统计服务器空间；离线统计使用本地缓存和变更后合并刷新，不新增后端接口。

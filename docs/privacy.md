# 简记浏览器插件隐私说明

最后更新：2026-10-28

本说明适用于 Chrome 与 Microsoft Edge 的“简记 · 浏览器笔记”插件。插件是自托管简记服务器的客户端，不内置开发者运营的笔记云服务，不包含广告、使用分析或浏览行为追踪代码。

## 处理哪些数据

- **服务器连接信息**：用户填写的服务器地址、客户端会话 Token 和到期时间保存在当前浏览器配置的本地扩展存储中，用于连接与维持登录。窗口位置、尺寸和界面主题也保存在本地，不使用浏览器账号的云端同步存储。
- **访问密码**：用户主动输入的服务器密码或文件夹密码会发送到用户指定的服务器完成验证。插件不长期保存原始密码。
- **笔记与附件**：仅在用户使用笔记功能时，从指定服务器读取笔记、文件夹及图片，或向该服务器保存笔记、上传图片、整理目录和生成分享。笔记内容可能包含用户自行输入的个人信息。
- **临时草稿**：未保存文字与待上传图片保留在当前窗口内存中，不作为离线笔记库持久化。刷新、关闭窗口或浏览器异常退出可能丢失这些内容。

开发者不会通过插件自建的分析或遥测接口接收上述数据，不会出售笔记或将其用于广告。用户选择的服务器运营方按其自身部署方式处理请求和日志；若服务器不是本人运营，请了解该服务的隐私规则。

## 网络与权限

`storage` 权限用于保存连接会话和窗口设置。可选 HTTP / HTTPS 主机权限用于连接用户手动指定的服务器，只有用户授权后才访问相应主机；浏览器的主机授权范围无法精确限定端口或路径。

插件不申请浏览历史、网页内容注入或任意网页剪贴板读取权限。图片粘贴由用户主动触发。插件代码及编辑器依赖随安装包提供，不从服务器下载并执行 JavaScript。

笔记中自行嵌入的外部图片或视频可能请求对应资源提供方。公开分享仅在用户主动生成链接时启用，链接持有者可在有效期内阅读该快照。受密码保护的文件夹暂停公开分享。

HTTPS 连接可保护传输过程；HTTP 不提供该保护。文件夹密码用于访问控制，不是磁盘加密：简记服务器将其按原样存入目录内的 `.pwd` 文件，便于服务器管理者找回。

## 清除与控制

可在插件连接设置中退出登录或切换服务器，清理本地连接状态；退出时会尝试撤销服务端会话，离线退出可能无法完成远程撤销，会在界面提示。服务端会话最长 30 天后到期。

卸载插件会移除浏览器中的扩展本地存储，但不会删除服务器笔记。笔记、附件、分享及服务端日志应由用户或服务器管理者在相应服务器上管理。删除笔记、取消分享及备份维护方式见项目文档。

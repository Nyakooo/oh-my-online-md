# 服务器离线同步验证记录

日期：2026-10-29。本阶段完成普通服务器笔记的可选离线缓存和双向同步；独立本地库继续通过显式单向导入复制到服务器。

## 验证环境

使用临时 data 目录、动态回环端口、独立浏览器配置及真实 Chromium MV3 扩展。切换服务器场景使用两个独立实例，没有连接真实笔记服务器。测试副本预授予临时主机权限，分发包保留可选主机权限。

## 自动化覆盖

- 断网保存正文与图片、创建笔记、移动/重命名文件夹，关闭并重启浏览器后恢复缓存和队列。
- 单边上传/下载、双边修改生成带图片的冲突副本；删除与修改冲突保留修改，正常删除双向传播。
- 目录并发修改保留服务器顺序并合并目录；单边离线排序上传。
- 服务端已提交但响应丢失后，再离线编辑、远端修改及重启浏览器，幂等重试不覆盖远端、不重复创建副本。
- 服务器身份变化暂停队列；两个地址的缓存、队列和内容隔离，切回原地址恢复待同步内容。
- 密码目录不下载；原普通笔记转入密码目录后，旧本地未同步修改转存独立本地库，不读取新受保护内容。
- 同步刷新请求被延迟时开始输入，响应返回后仍保留用户输入和未保存状态。
- 服务端版本校验、删除重试、目标身份验证、已提交回执重放、事务准备/旧目录移动/发布阶段的启动恢复。
- 同步替换保留分享快照、用户自建文件、附件子目录和其他窗口尚未引用的新上传，只清理旧正文已引用而新提交删除的应用图片；附件变更使同步版本失效。

## 实测范围与限制

原生主机权限弹窗、系统快捷键冲突和 Edge 桌面表现仍需在目标机器人工验收。当前环境没有 Nginx，未启动实际反向代理；请求上限由后端检查，部署模板保留 232m。

受保护目录、分享操作在直接在线模式使用。同步只在插件窗口打开期间运行；关闭后持久队列在下次打开恢复。未保存输入不持久化；外链媒体不保证离线。缓存备份包含当前已保存内容，不包含操作队列和连接凭据。浏览器缓存明文存储，需要定期导出备份。

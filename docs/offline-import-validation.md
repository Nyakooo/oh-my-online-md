## 关键场景

### 独立离线笔记

- 无网络时保存正文和 Blob 图片，刷新后仍可读取；实际关闭并重启浏览器后笔记保留。
- 本地与服务器模式隔离，切换不会自动上传；取消切换保留未保存内容。
- 文件夹重命名保留排序和当前笔记的可保存状态；旧窗口不能覆盖或删除其他窗口的新版本。
- 图片超过 10 MiB、正文超过 16 MiB 时拒绝写入，已有正文保留。已有笔记保留的情况下，实际连续写入 19 张 10 MiB 图片后，下一张被 200 MiB 总容量限制拒绝；删除容量测试笔记后原有笔记仍完整。
- 完整备份追加恢复正文、文件夹和图片；恢复图片字节长度符合原件。损坏附件备份被整体拒绝，既有数据数量不变。
- 从第一阶段 IndexedDB v1 升级至 v2 后，原有笔记和图片可继续使用。

### 选择导入服务器

- 默认不选中笔记，只有明确勾选并确认才发送；未选中的笔记和本地原件保留。
- 图片、Markdown 引用式链接和 HTML 图片地址迁移后可读；实际预览能解码图片。
- 代码块、行内代码、普通文字、非目标 HTML 属性和属性内的示例 HTML 保持原文。
- 模拟服务器成功保存但响应丢失，再关闭并重启浏览器重试：目标只出现一份笔记。
- 服务重启、并发提交同一导入 ID 和已完成的再次操作都不产生重复笔记。
- 同一导入 ID 携带不同数据会被拒绝；服务器上的后续编辑不被导入重试覆盖。
- 不同服务器使用独立身份与进度；提交中的身份不匹配会拒绝，不误写目标。
- 缺失或伪造图片、路径越界、受保护同名文件夹被拒绝，不暴露半成品笔记。
- 导入窗口在 390 × 844 的窄窗口中保持在视口范围内；已检查桌面实际截图。

## 实测范围与限制

自动化运行于 Chromium 的真实 Manifest V3 环境；原生动态权限确认、系统快捷键冲突和 Edge 桌面操作仍需在目标机器人工验收。测试副本仅预授予临时服务器主机权限，分发包仍使用可选主机权限。

当前环境没有 Nginx，因此没有启动实际反向代理做上传测试；Nginx 模板已更新为 232 MiB，后端本身执行独立的正文、图片及总请求限制。

本阶段是单向复制，不是双向同步。当前失败笔记的附件整体重传，不做单文件分块续传。导入后的新本地版本创建新服务器副本，不更新旧副本；空文件夹和本地排序不迁移。浏览器导入进度不包含在笔记备份中。

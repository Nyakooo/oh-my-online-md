# 简记浏览器扩展

Chrome / Edge 的 Manifest V3 扩展。无需服务器即可使用本地离线笔记，也可填写自己的简记服务器地址。通过扩展图标或快捷键打开独立笔记窗口，使用文件夹、Markdown 编辑器和图片功能。

## 下载与安装

从 [最新 Release](https://github.com/Nyakooo/oh-my-online-md/releases/latest) 下载 `oh-my-online-md-extension_v版本号.zip`，解压后安装，无需本地构建。

Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`，启用“开发者模式”，选择“加载已解压的扩展程序”，选择解压后包含 `manifest.json` 的目录。安装后可将图标固定到工具栏。更新时用新版文件替换该目录，再在扩展管理页点击“重新加载”。

服务器和插件建议使用同一发布版本。服务器升级方式见 [部署文档](deployment.md)。

## 从源码构建

使用服务器模式时，服务器需要先更新到包含 `/api/client/info` 和客户端会话接口的本版本；旧服务器会在连接时提示升级。浏览器至少需要 Chrome 116 或支持对应扩展接口的近期 Edge。

```sh
pnpm install --frozen-lockfile
pnpm typecheck:extension
pnpm build:extension
```

构建生成：

- `dist/extension/`：可直接加载的扩展目录。
- `dist/oh-my-online-md-extension.zip`：可分发的 ZIP（构建环境需要 `zip` 工具）。

Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`，启用“开发者模式”，选择“加载已解压的扩展程序”，选择 `dist/extension` 目录。若收到 ZIP，先解压，再选择其中包含 `manifest.json` 的目录。首次加载后可将扩展图标固定到工具栏。

## 连接服务器

1. 点击简记图标，或按 `Ctrl+Shift+Y`（macOS 为 `Command+Shift+Y`）。
2. 输入服务器地址，例如 `https://notes.example.com` 或 `http://192.168.1.10:10777`。代理在子路径部署时可填写完整前缀，例如 `https://example.com/notes`，代理需要把该前缀剥离后转给 Go 服务。
3. 点击“测试连接”或“连接并打开笔记”，允许浏览器访问所填服务器。
4. 输入服务器的 `PASSWORD`；服务器没有设置密码时留空。
5. 连接成功后进入笔记界面。工具栏的设置按钮可重新连接、切换服务器或退出登录。

浏览器授权按协议和主机匹配，不能精确限制到端口或子路径；扩展自身只向当前填写的完整地址发送认证请求。HTTP / HTTPS 分别授权，HTTPS 证书需要浏览器信任，扩展不会跳过证书校验。HTTP 链路上的内容和密码不会被自动加密。

快捷键被占用时，可在连接设置底部点击“修改”。默认只在浏览器获得焦点时生效，不是系统全局快捷键。再次唤出会恢复并聚焦已有窗口；后台休眠后仍能找到窗口，窗口关闭后可重新创建，并记住正常窗口的大小和位置。

## 笔记和访问控制

直接在线模式下，插件与网页共用编辑、预览、搜索、图片粘贴、文件夹拖拽整理、分享及主题功能。外层笔记在文件夹上方，笔记、文件夹及文件夹内笔记支持各自拖拽排序，顺序保存在服务器并共用。笔记仍实时读写服务器实际目录；`.pwd` 仍只保存在服务器文件夹内。受保护目录的分享规则保持不变。

- 扩展不长期保存服务器或文件夹的原始密码。客户端 Token 保存在扩展本地，最长有效 30 天；服务器只保存 Token 摘要，文件为 `DATA_DIR/.client-sessions.json`，权限 `0600`。
- 网页 Cookie 登录保持原有规则；客户端 Token 使用独立签名域，不能转换成网页登录 Cookie。
- 文件夹解锁绑定当前客户端的当前窗口，闲置 5 分钟自动锁定。设置或更改密码、刷新、关闭窗口、收起目录、切换到目录外笔记、重新登录或服务器重启后需要重新解锁。不同窗口不共享解锁状态。闲置锁定时未保存草稿与待上传图片只保留在当前窗口内存，解锁后可继续；刷新或关闭会丢失。
- 退出登录、同服务器重新连接和切换服务器会尝试撤销旧会话；切换主机还会移除旧的主机授权。旧服务器无法访问时，仍允许本地退出或切换，并明确提示远程会话未撤销。旧 Token 在到期前可能仍有效，可在服务器上删除 `.client-sessions.json` 撤销全部客户端会话。
- 切换服务器前提示处理未保存修改，确认切换后清空旧笔记、图片和文件夹状态。同服务器重新登录保留当前未保存内容。
- 图片使用带权限的请求加载为临时 Blob URL，Token 不写入图片或分享链接。
- 网页与扩展保存时使用笔记版本校验；其他窗口已经修改时保留本地内容，提供保留编辑或明确放弃本地并重新加载的选择。旧客户端没有版本参数的保存请求继续兼容原有行为。

服务器模式可在连接设置中主动开启“离线同步”，首次需要在线建立缓存。独立本地模式及服务器缓存均保存已保存的笔记，两种模式均不持久化尚未保存的编辑。本地笔记可以手动选择后单向导入服务器。服务器断网或登录过期时保留当前打开窗口里的未保存内容；关闭窗口仍会提示处理修改。浏览器崩溃或强制结束进程可能丢失未保存编辑。

## 验证

```sh
pnpm exec playwright install chromium
pnpm test:extension
# 所有网页与扩展回归
bash scripts/test-browser.sh
```

统一测试入口会创建自己的临时服务器、端口、浏览器配置与数据目录。扩展测试使用真实 MV3 运行环境，覆盖连接、登录、编辑保存、权限图片、Mermaid、文件夹、窗口复用、后台终止后恢复、冲突、切换服务器以及离线退出。

无头浏览器无法点击原生的动态主机授权提示，自动化测试只在临时副本中预先授予测试服务器主机权限。分发包保留可选权限；实际安装时的原生权限提示、系统快捷键冲突及 Edge 桌面表现需要在目标机器验收。没有网页注入或浏览历史读取功能。

## 本地离线使用

打开插件设置，选择“打开本地笔记（无需服务器）”，即可在没有网络和后端的情况下编辑、搜索、整理文件夹和粘贴图片。笔记和图片保存在当前浏览器配置文件的 IndexedDB 中，关闭窗口、重启浏览器后保留。

本地笔记与服务器笔记是独立工作空间。切换模式不会上传、合并或删除数据。连接本机后端时填写 `http://127.0.0.1:10777`；本地后端停止时，已开启离线同步的服务器工作空间可继续编辑缓存；未开启时会提示连接失败。

本地总容量上限为 200 MiB，单张图片最多 10 MiB，单篇正文最多 16 MiB。不支持公开分享和文件夹访问密码，外链图片需要网络。插件申请 `unlimitedStorage` 以避免浏览器配额和自动驱逐影响本地笔记，应用自身仍执行容量限制。

请定期在插件设置中“导出本地完整备份”。JSON 备份包含已保存的正文、文件夹、排序和图片，不包含尚未保存的编辑内容。卸载插件或删除浏览器配置文件可能丢失本地数据。

“导入本地备份（追加）”会保留现有笔记，为导入笔记分配新 ID，同名文件夹合并；重复导入会产生多份笔记。导入校验及写入是整体操作，失败不会只导入一部分。备份文件上限为 300 MiB，导入后仍受本地总容量限制。


## 将本地笔记导入服务器

1. 在插件设置中连接目标服务器。后端需支持本版本的 `/api/import/info` 和 `/api/import/notes/{id}` 接口。
2. 点击“选择本地笔记导入已连接的服务器”，检查窗口中显示的目标地址。
3. 勾选需要复制的本地笔记，再点击“导入所选”。默认不选择任何笔记，切换模式不会自动上传。

导入以打开选择窗口时已保存的版本为准，不包含未保存的编辑。本地原件和已有服务器笔记均保留；同名普通文件夹合并，受保护的同名文件夹拒绝导入，需先重命名本地文件夹。空文件夹和本地手动排序不在本阶段的导入范围内。

每篇笔记连同图片完整提交后才在服务器可见。某篇失败时，之前完成的笔记保留，尚未完成的可以再次选择导入；关闭、重启浏览器后仍保留进度。即使服务器已成功保存但响应丢失，重试同一版本也不会创建重复笔记或覆盖服务器上的后续编辑。目标服务器地址与数据身份隔离，换服务器会建立独立进度。

此导入操作是单向复制。本地修改后再次导入会创建新副本，不更新之前导入的服务器笔记。导入记录保存在当前浏览器中，不包含在本地笔记备份中；备份追加恢复产生新笔记 ID，按新的本地副本处理。已经完成的同一版本不会因服务器笔记后来被删除而自动重新上传。

单篇正文仍最多 16 MiB、单图最多 10 MiB，整篇导入请求最多 232 MiB。如果反向代理返回 413，请按部署文档调整导入请求的上传限制。断网或登录失效后，重新连接同一服务器并再次选择笔记重试即可；当前失败笔记的附件会整体重传，不支持单个文件的分块续传。


## 服务器离线同步

连接服务器后，在设置中开启离线同步。首次初始化完成后，普通笔记、文件夹、排序及自有图片保存在该服务器独立的 IndexedDB 中；断网仍可打开和保存。保存后及窗口在线期间定期同步，也可点击“立即同步”。关闭窗口会暂停网络同步，下次打开继续。登录过期时保留缓存和队列，重新连接后恢复。切换服务器不会把队列发往其他地址；服务器身份变化时暂停同步。

双边修改会保留服务器原件并创建本地修改的冲突副本，设置页显示处理结果。删除和修改冲突保留修改；结构同时变化时保留服务器排序并合并普通文件夹。离线同步不提供密码文件夹和分享操作，需要关闭同步后使用直接在线模式；有待同步操作时禁止关闭。普通笔记后来受保护时，不读取新的受保护内容，未同步的旧本地修改转存独立本地笔记库。

“导出缓存备份”导出当前已保存笔记和图片，可追加恢复到独立本地库；不包含同步操作队列、服务器连接信息或受保护笔记。卸载前应分别备份独立本地库与各服务器缓存。缓存不是加密存储。外链图片、视频不保证离线可用，插件界面和编辑器静态资源随安装包提供。

本次更新简化访问验证：设置 `PASSWORD` 后，使用仅包含密码输入框的登录页，无需用户名。

- 登录状态通过 HttpOnly、SameSite Cookie 保留，HTTPS 下启用 Secure 标记。
- 修改 `PASSWORD` 后，原有登录状态失效。
- 未设置密码时直接进入笔记，公开分享链接保持免登录只读访问。
- 登录过期时保留当前未保存内容，并提示重新登录。

## 更新

```sh
docker compose pull
docker compose up -d
```

固定版本部署请将 `IMAGE_TAG` 设置为 `v1.0.1`。现有密码与数据目录无需修改。更新后首次访问需要在新登录页输入密码，原有 Basic Auth 凭据不再使用。

GHCR 镜像和 Linux 二进制均支持 amd64、arm64；下载后可通过 `SHA256SUMS` 验证二进制压缩包。

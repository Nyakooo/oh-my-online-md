本次发布修复 v1.4.2 在桌面与手机布局之间切换时，菜单展开状态互相影响的问题，并包含 v1.4.2 的侧栏及笔记切换优化。

## 更新内容

- 桌面侧栏与手机抽屉分别保存展开状态；桌面展开侧栏不再导致首次切换到手机布局时抽屉自动打开。
- 手机抽屉支持点击外部或按 Esc 关闭。
- 恢复原深色灰阶配色，移除预览阶段遗留的暖色覆盖。
- 修复离开受保护文件夹后目录锁定状态未刷新的问题，立即清除缓存的私密条目。
- 补充跨布局状态记忆、触控布局、键盘关闭和外部点击关闭回归。
- 保留统一目录入口、全宽布局、原白天主题和笔记切换防闪动优化。

## 下载与安装

- `oh-my-online-md-extension_v1.4.3.zip`：Chrome / Edge 插件。解压后加载已解压的扩展程序；已安装用户替换原目录文件后重新加载。
- `online-md_v1.4.3_linux_amd64.tar.gz`、`online-md_v1.4.3_linux_arm64.tar.gz`：Linux 服务器程序。
- `SHA256SUMS`：发布压缩包校验和。

容器镜像：`ghcr.io/nyakooo/oh-my-online-md:v1.4.3`。

v1.4.2 的 CI 在手机搜索回归中失败，镜像发布及 Release 创建未执行。本版本修复该失败路径，GitHub Actions 完整验证成功后自动发布。

本次发布新增 Chrome / Edge 浏览器插件与服务器文件夹联动，完善密码访问、拖拽整理及并发保存保护。

## 更新内容

- **浏览器插件**：手动配置服务器，通过 `Ctrl+Shift+Y`（macOS：`⌘⇧Y`）唤出独立笔记窗口，支持编辑、预览、搜索、图片和分享。
- **文件夹**：对应服务器实际目录，独立笔记排在文件夹上方，支持拖拽移入、移出及排序，网页和插件共用顺序。
- **密码访问**：文件夹密码保存到目录内的 `.pwd`，按原样明文存储以便服务器端找回。解锁只作用于当前窗口，收起、离开、刷新、关闭及闲置五分钟后重新锁定；闲置时草稿仅保留在当前窗口内存中。
- **保存保护**：增加版本校验，避免网页和插件同时编辑时无提示覆盖。
- **界面整理**：采用猫耳便签 Logo，更新宣传图，移除“移动”按钮，并精简项目文档。

## 下载与安装

- `oh-my-online-md-extension_v1.3.0.zip`：Chrome / Edge 插件，解压后在扩展管理页面开启开发者模式，选择“加载已解压的扩展程序”。无需 Node.js 或本地构建。
- `online-md_v1.3.0_linux_amd64.tar.gz`、`online-md_v1.3.0_linux_arm64.tar.gz`：Linux 服务程序。
- `SHA256SUMS`：上述压缩包的 SHA-256 校验和。
- GitHub 自动提供的 Source code ZIP / tar.gz 是项目源码，不是可安装的插件包。

插件操作与服务器连接说明见 [插件指南](https://github.com/Nyakooo/oh-my-online-md/blob/v1.3.0/docs/browser-extension.md)。插件未上架商店，请使用本 Release 的 ZIP 安装。

## 升级

升级前备份整个数据目录。已有笔记无需迁移；新建的排序与客户端会话元数据也存于数据目录中。

容器镜像：`ghcr.io/nyakooo/oh-my-online-md:v1.3.0`。固定版本部署在 `.env` 中设置 `IMAGE_TAG=v1.3.0`，然后执行：

```sh
docker compose pull
docker compose up -d
```

跟随 `latest` 的部署也可执行 `bash deploy.sh`。源码部署先 `git pull --ff-only`。插件用户需用新包替换解压目录并在扩展管理页重新加载；网页升级后刷新页面。服务器和插件建议同步更新。

文件夹密码是访问控制，不是磁盘加密；备份包含 `.pwd`，请妥善保存。公开分享仅开放笔记快照，受保护文件夹内的笔记暂停公开分享。

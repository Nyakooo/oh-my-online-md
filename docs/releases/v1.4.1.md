本次发布优化网页端与 Chrome / Edge 插件的 Markdown 工具栏，让编辑功能更容易辨认。

## 更新内容

- 将 15 个字符图标替换为统一的 SVG 图标，清楚区分链接、列表、代码、表格、图表、图片和视频。
- 添加功能分组间隔，统一图标尺寸与线条。
- 悬停及键盘聚焦时立即显示提示，无延迟和过渡动画。
- 提示根据屏幕边缘调整位置，适配深浅主题及窄屏布局。

## 下载与安装

- `oh-my-online-md-extension_v1.4.1.zip`：Chrome / Edge 插件。解压后在扩展管理页加载已解压的扩展程序；已安装用户替换原目录文件后重新加载。
- `online-md_v1.4.1_linux_amd64.tar.gz`、`online-md_v1.4.1_linux_arm64.tar.gz`：Linux 服务器程序。
- `SHA256SUMS`：发布压缩包校验和。

容器镜像：`ghcr.io/nyakooo/oh-my-online-md:v1.4.1`。

## 验证

编辑及媒体浏览器回归测试通过。工具栏的 15 个图标及即时提示已在 1440、768、375 像素宽度、深浅主题下检查。

本次发布同步优化网页端和 Chrome / Edge 插件的侧栏与编辑布局，并修复切换笔记时菜单闪动的问题。

## 更新内容

- 侧栏支持收起并记住状态；收起后保留新建、搜索和笔记目录入口，底部可固定展开。
- 笔记目录悬停预览，点击保持打开；点击外部或按 Esc 关闭。浮层直接复用原目录，保留排序、选中、文件夹解锁和拖拽功能。
- 全屏布局铺满窗口，缩小正文两侧留白，调整圆角和轻微回弹动效；白天主题沿用原配色。
- 移除编辑区底部的 Markdown、快捷键和图片上传提示文案，保留原有功能。
- 修复收起栏点击时目录闪开闪关、搜索无法立即聚焦等交互问题。
- 切换笔记不再隐藏侧栏按钮或降低目录透明度；普通切换保留列表节点，仅更新选中项。

## 下载与安装

- `oh-my-online-md-extension_v1.4.2.zip`：Chrome / Edge 插件。解压后加载已解压的扩展程序；已安装用户替换原目录文件后重新加载。
- `online-md_v1.4.2_linux_amd64.tar.gz`、`online-md_v1.4.2_linux_arm64.tar.gz`：Linux 服务器程序。
- `SHA256SUMS`：发布压缩包校验和。

容器镜像：`ghcr.io/nyakooo/oh-my-online-md:v1.4.2`。

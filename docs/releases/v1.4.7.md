## 更新内容

- 修复网页左侧目录溢出后无法上下滚动的问题。
- 限制目录布局高度，避免列表条目被压缩，并保持细滚动条样式。

## 下载与安装

- `oh-my-online-md-extension_v1.4.7.zip` 为 Chrome / Edge 插件。解压后加载扩展，已安装用户可替换原目录文件后重新加载。
- `online-md_v1.4.7_linux_amd64.tar.gz` 和 `online-md_v1.4.7_linux_arm64.tar.gz` 为 Linux 服务器程序。
- `SHA256SUMS` 提供发布压缩包的校验和。

容器镜像为 `ghcr.io/nyakooo/oh-my-online-md:v1.4.7`。

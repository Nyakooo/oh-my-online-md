简记首个正式版本。轻量级自托管 Markdown 笔记应用，基于 Go 与本地文件存储，无需数据库。

## 主要功能

- 行内 Markdown 编辑，编辑位置以外的内容自动呈现排版。
- 图片粘贴，保存时上传，保存后清理移除引用的附件。
- 限时只读分享，使用正文和图片快照，支持重新生成及提前取消。
- 手动保存、真实修改状态识别、中文输入与撤销重做。
- 日间模式和黑白灰夜间模式，适配电脑、平板与手机。

## 部署

GHCR 镜像提供 `linux/amd64` 和 `linux/arm64`：

```sh
docker pull ghcr.io/nyakooo/oh-my-online-md:v1.0.0
```

也可以下载 `compose.yaml` 并设置 `.env` 后使用 Docker Compose 部署。已有部署固定版本时，将 `IMAGE_TAG` 设置为 `v1.0.0` 后重新拉取并启动。

Linux 二进制压缩包分别对应 amd64 与 arm64，附带 MIT 及第三方许可证；使用 `SHA256SUMS` 验证下载内容。

## 数据兼容

已有 `note.md` / `meta.json` 笔记目录无需迁移。更新前备份整个数据目录；停止或更新容器不会删除挂载的数据。

图片单次上传上限为 10 MiB。使用 Nginx 时设置 `client_max_body_size 10m;`，完整示例包含在下载资产中。

详细配置与使用方式见 [README](https://github.com/Nyakooo/oh-my-online-md/tree/v1.0.0#readme)。

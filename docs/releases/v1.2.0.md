本次更新完善 Markdown 编辑、媒体尺寸控制与分享体验，并增加服务器一键部署脚本。

- **编辑与预览**：采用类似 GitHub Issues 的“编辑 / 预览”页签，保留光标和撤销记录；新增常用 Markdown 格式工具栏。
- **键盘操作**：支持 Tab / Shift+Tab 缩进、加粗、斜体、链接、行内代码及预览切换等快捷键，保留中文输入支持。
- **加载反馈**：首次进入与切换笔记显示加载动画和骨架屏，连接失败后可以重试。
- **Mermaid 图表**：支持预览、放大、缩小、重置和 Ctrl / ⌘ + 滚轮缩放，组件按需加载。
- **图片与视频**：支持 HTML `img`、`video`、`source` 标签及尺寸设置；选中已有图片的 Markdown 或 HTML 后，可通过“图片尺寸”修改宽高。视频支持链接嵌入，暂不提供上传。
- **安全 HTML**：支持常用排版与折叠标签，过滤脚本、事件属性及危险链接；HTML 图片继续参与附件清理和分享快照。
- **图片输入**：支持粘贴、拖放与文件选择，保存前保留在浏览器本地。
- **分享主题**：分享页可手动切换白天 / 黑夜模式，记住浏览器中的主题偏好；未选择时跟随系统。
- **服务器更新**：根目录新增 `deploy.sh`，自动检查配置、拉取镜像、更新容器、检查服务并清理悬空镜像，带重复运行锁和失败诊断。

## 更新

已有源码部署先同步脚本和配置，再执行：

```sh
git pull --ff-only
bash deploy.sh
```

固定版本部署请在 `.env` 中设置 `IMAGE_TAG=v1.2.0` 后运行脚本。仅下载 Compose 配置部署的用户，可下载本 Release 的 `deploy.sh`，将它与 `compose.yaml`、`.env` 放在同一目录后执行 `bash deploy.sh`。

脚本需要 Bash、curl、flock 与 Docker Compose v2。默认清理整个 Docker 守护进程的悬空镜像，使用 `bash deploy.sh --no-prune` 可跳过清理；脚本不删除数据卷，也不自动备份数据。

也可以手动更新：

```sh
docker compose pull
docker compose up -d
```

已有笔记无需迁移，升级前建议备份整个数据目录。Linux amd64 / arm64 二进制及校验和见下方附件；容器镜像为 `ghcr.io/nyakooo/oh-my-online-md:v1.2.0`。

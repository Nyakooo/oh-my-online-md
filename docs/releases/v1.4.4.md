本次发布为网页端和 Chrome / Edge 插件增加 Markdown 工具栏吸顶，方便长文编辑和预览。

## 更新内容

- 正文滚动时，编辑 / 预览切换与 Markdown 格式工具栏固定在顶部导航下方。
- 适配桌面与手机工具栏换行布局，滚动到文末仍可操作。
- 保持原有主题配色、快捷键、格式按钮和预览功能。

## 下载与安装

- `oh-my-online-md-extension_v1.4.4.zip`：Chrome / Edge 插件。解压后加载已解压的扩展程序；已安装用户替换原目录文件后重新加载。
- `online-md_v1.4.4_linux_amd64.tar.gz`、`online-md_v1.4.4_linux_arm64.tar.gz`：Linux 服务器程序。
- `SHA256SUMS`：发布压缩包校验和。

容器镜像：`ghcr.io/nyakooo/oh-my-online-md:v1.4.4`。

## 验证

网页及实际插件页面的吸顶回归通过，覆盖桌面、手机、深浅主题、编辑 / 预览、长文末尾和格式按钮操作。原有编辑回归与 320–768px 移动端触控仿真通过。

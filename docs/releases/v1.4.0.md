本次发布为 Chrome / Edge 插件增加独立离线笔记及可配置空间上限，无需部署或启动后端服务即可使用。

## 更新内容

- **独立离线模式**：笔记、图片、文件夹和排序保存在浏览器 IndexedDB 中，断网和重启浏览器后仍可使用。
- **完整备份**：支持导出正文、目录、排序及图片；追加恢复分配新 ID，保留原有笔记，校验失败整体回滚。
- **空间管理**：侧栏常驻显示已用空间和上限；默认 200 MiB，可在设置中调整，不能低于当前用量。达到 80% 和 95% 时提醒。
- **性能控制**：离线用量使用本地缓存和变更后合并刷新，无周期轮询；在线模式不查询服务器空间。
- **界面整理**：窗口使用新版猫咪 favicon，移除侧栏重复图标和“简记”文字，保留窗口标题。
- **发布校验**：项目版本、插件清单、tag 和插件 ZIP 名称统一为 1.4.0，构建和 CI 自动检查一致性。

在线模式仍直接连接自建服务器，与离线笔记完全隔离。切换模式不上传、合并或同步数据；本版本不提供本地笔记导入服务器、服务器离线缓存或双向同步，不新增对应后端接口。

## 下载与安装

- `oh-my-online-md-extension_v1.4.0.zip`：Chrome / Edge 插件。解压后在扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，再选择“打开本地笔记（无需服务器）”。
- `online-md_v1.4.0_linux_amd64.tar.gz`、`online-md_v1.4.0_linux_arm64.tar.gz`：可选的 Linux 服务器程序，离线使用插件无需下载。
- `SHA256SUMS`：压缩包的 SHA-256 校验和。
- GitHub 自动提供的 Source code ZIP / tar.gz 为项目源码，不是可安装插件。

升级插件时使用新版文件替换原解压目录，并在扩展管理页重新加载，关闭后重新打开笔记窗口。原有离线库会原地升级并保留内容；升级或卸载前建议导出完整备份。旧版在线插件也可按原方式继续连接服务器。

## 限制与验证

离线单图最多 10 MiB，单篇正文最多 16 MiB；调整总容量上限不改变这两项限制。实际可用空间仍受设备和浏览器环境影响。离线模式不支持分享或密码文件夹，外链媒体需要网络，未保存内容仅保留在当前窗口内存中。

全部 13 组 Chromium 浏览器回归、扩展类型检查、Go 竞态检测和静态检查通过。原生主机权限弹窗、系统快捷键冲突及 Edge 桌面表现需在目标机器验收。

使用说明见 [插件指南](https://github.com/Nyakooo/oh-my-online-md/blob/v1.4.0/docs/browser-extension.md)。容器镜像沿用原发布方式：`ghcr.io/nyakooo/oh-my-online-md:v1.4.0`。

重新访问网页或打开 Chrome / Edge 插件时，会恢复上次打开的笔记。

## 更新内容

- 网页、插件本地模式和插件连接的各台服务器分别记录上次打开的笔记。
- 上次打开的笔记位于受保护的文件夹时，输入文件夹密码后继续查看。

## 下载与安装

- `oh-my-online-md-extension_v1.4.5.zip` 为 Chrome / Edge 插件。解压后加载已解压的扩展程序。已安装用户可替换原目录中的文件，再重新加载插件。
- `online-md_v1.4.5_linux_amd64.tar.gz` 和 `online-md_v1.4.5_linux_arm64.tar.gz` 为 Linux 服务器程序。
- `SHA256SUMS` 提供发布压缩包的校验和。

容器镜像为 `ghcr.io/nyakooo/oh-my-online-md:v1.4.5`。
